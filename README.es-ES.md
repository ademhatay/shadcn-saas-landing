

# Landing Page SaaS con Shadcn UI

Landing page fácilmente personalizable para un producto SaaS, construida con React, Tailwind CSS y ShadCn UI.

Este proyecto de código abierto es una landing page para un producto SaaS. Está construido con React, Tailwind CSS y ShadCn UI. Es totalmente responsivo y fácil de personalizar.

## Instalación

1. Clona el repositorio
    `git clone https://github.com/ademhatay/shadcn-saas-landing` 
2. Cambia al directorio
    `cd shadcn-saas-landing` 
3. Instala las dependencias
    `bun install` 
4. Inicia el servidor de desarrollo    
    `bun dev` 
5. Abre [http://localhost:5173](http://localhost:5173/) en tu navegador
